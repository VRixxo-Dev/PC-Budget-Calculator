# PC Budget Calculator

A long-term C#/.NET project focused on PC budget planning and component cost management. Starting as a console application, PC Budget Calculator is intended to evolve into a fully featured GUI application with expanded functionality, improved usability, and more advanced budget management tools.

## Overview

PC Budget Calculator is designed to help users plan potential PC builds while keeping track of their available spending budget and individual component costs.

This project serves as an ongoing development effort to build, improve, and expand an application using the C# and .NET ecosystem.

The initial release focuses on establishing the application's core functionality through a console-based interface. Future development will gradually introduce a graphical user interface (GUI), additional features, and a more complete user experience.

## Project Goals

The long-term vision for PC Budget Calculator includes:

- **GUI Development:** Transition from a console application to a fully featured desktop application.
- **Budget Management:** Provide better tools for tracking and managing PC build budgets.
- **Component Management:** Organize and manage individual PC components and their associated costs.
- **Build Planning:** Allow users to plan, compare, and manage potential PC configurations.
- **Data Persistence:** Save, load, and manage budget configurations between sessions.
- **User Experience:** Introduce a modern, intuitive interface with improved navigation and usability.
- **Continuous Development:** Maintain and expand the project as my knowledge of C# and .NET grows.

## Current Features

- User information collection.
- Custom budget input.
- Individual PC component cost input.
- Budget and expense calculations.
- Numerical input parsing and validation.
- Interactive console-based interface.

## Getting Started

### Prerequisites

- [.NET SDK](https://dotnet.microsoft.com/download)
- A terminal or code editor.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/PC-Budget-Calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd PC-Budget-Calculator
   ```

3. Run the application:

   ```bash
   dotnet run
   ```
